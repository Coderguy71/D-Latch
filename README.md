This is the verilog and constraint file of a Synchronous set/reset flipflop. The SSRFF takes an input and "remembers" it, leaving the onboard LED as on. It also takes a reset input to reset the LED. 
The inputs are the user buttons, the outputs is LED0. This code works in GowinIDE utilizing a GW2AR-LV18QN88C8/I7 Tang Nano 20k FPGA Board.
